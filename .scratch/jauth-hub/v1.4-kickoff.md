## 实战教训(v1.3 付费买来的,新会话直接受益)

- **配额会杀死在途 subagent**(v1.2 遗训,v1.3 再验证):派单词写成"自包含+可代执"形态,主会话照单无缝接手(D1–D5 全程主会话代执行验证)
- **git 门指纹顺序:先 `git add` 暂存 → 再 review-mark → 再 commit**;暂存后任何语义改动(含格式化)都需重新标记
- **框架 API 以解析 jar 的 javap 为准**:OAuth2AuthorizationConsentService 在 7.1.1 只有 findById(D4 教训——记忆里的 findByClientIdAndPrincipalName 是旧 SAS 形状)
- **Boot 4.1 spring-session-jdbc 默认仓库非索引**(FindByIndexNameSessionRepository 无 bean,repository-type=indexed 拉不回)——按主体会话操作走自家 vendored DDL 直删
- **族谱表 jauth_token_family_client_fk ON DELETE CASCADE**:删 client 行连带清族谱行——按 client 级联的可观察契约是"无 ACTIVE 残留"而非"BURNED 在册"
- RegisteredClient.from()+redirectUri() 是**追加**语义——编辑须 Consumer 形态先 clear 后 add
- **oauth2_consent 表名实为 oauth2_authorization_consent**(框架命名,别按直觉写)
- JdbcOwnedAppService 的 ownerColumn 拼 SQL 前先收声:列名来自固定白名单(null 判分支),无注入面——同类写法照此注释
- PS 5.1 双引号/批处理脚本.py 的宽匹配替换会误伤相邻构造——改一处先看上下文五行走稳;测试构造批量打补丁后立即编译验证
- v1.2 及更早教训仍有效(详见 v1.3-kickoff):locale 钉死、MockMvc standalone 无视图渲染、限流测试时序敏感全量并发下可能偶发(单跑即绿)、每批评审平均修出 1-3 条真问题
