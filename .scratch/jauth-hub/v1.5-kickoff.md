4. hook 已 v2+;门禁流程照 AGENTS.md;**门禁指纹顺序:review-mark 必须独立工具调用后再起 git 链(`mark && add && commit` 链式被 PreToolUse 整拦,v1.5 两次实证)**;subagent 自测在后台跑完会续报多次,以末次为准
5. 版本:里程碑即版本,发布遵循 docs/RELEASE_PROCESS.md(push→CI 绿→打 annotated tag;**tag 永不移动**)
6. **链式交接**:v1.5 收口时由当值会话写 `.scratch/jauth-hub/v1.6-kickoff.md`(现状快照 + 滑账清册 + 本铁律第 6 条原样自续),此后每阶段同理。永久路线图永远在 docs/SPEC.md §5——kickoff 只管当前一窗

## 实战教训(v1.4 付费买来的 + v1.5 已知风险)

- **AuthenticationManager 不可经 AuthenticationConfiguration 暴露为 bean**(全局构建器自递归 StackOverflow)——自组装 Dao ProviderManager(无 parent)+ 上下文感知事件发布器
- **CSRF 契约**:状态面原始 token 双通道(头/表单)可用;登录成功后 token 换发,每页重取状态面
- **copy-resources 对缺失源目录静默成功**——dist 依赖型 profile 必须 enforcer requireFilesExist 兜底(v1.5 的 front-dist 模块直接沿用此纪律)
- **v1.5 特有风险**:①SSR 拆除是全仓级联(Thymeleaf 依赖/视图解析器/viewNames 白名单/EducationalFlag 模板消费点/starter 装配),必须放最后一批且全量 verify 兜底;②demo 教学区内联 JS 量大,Vue 复刻以行为等价为准不逐字(流程图高亮/HTTP 日志/内省展示三件必须活);③admin/profile 页在 app 模块,API 缺口以 B0 普查为准不拍脑袋
- 网络瞬断成常态:push 失败挂后台重推循环;`git status -sb` + `ls-remote` 对账
- v1.3 及更早教训仍有效:javap-over-memory、PS 5.1 批量替换误伤、locale 钉死、MockMvc standalone 无视图渲染、限流测试时序敏感、每批评审平均修出 1-3 条真问题
